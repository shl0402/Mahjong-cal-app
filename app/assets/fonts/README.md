# Noto Sans TC

The variable TrueType font is bundled for Traditional Chinese UI and tile labels, including offline use.

Source: [Google Fonts / Noto Sans TC](https://github.com/google/fonts/tree/main/ofl/notosanstc)

License: SIL Open Font License 1.1, see `OFL.txt`.

Downloaded on 2026-10-02. `NotoSansTC.ttf` is the upstream `NotoSansTC[wght].ttf`, renamed only for a simple asset path.

SHA-256: `864727d210d54f2537bbe23b3a839436c3992af72de9322af5270897246bd44f`.

## Roboto

Flutter's browser renderer otherwise downloads Roboto during startup even when the theme uses another font. `Roboto.ttf` bundles the upstream variable `Roboto[wdth,wght].ttf` from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/roboto), under the adjacent `OFL-Roboto.txt` license.
